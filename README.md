## About

This repository contains the coursework, assignments, programming exercises, and projects completed as part of the **BridgeLabz 2nd-Year Java Training Program**.

The training focuses on strengthening Java programming fundamentals, object-oriented programming, problem solving, data structures and algorithms, exception handling, collections, testing, and software development practices.

---

## Objectives

* Strengthen Java programming fundamentals
* Develop structured problem-solving skills
* Apply Object-Oriented Programming principles
* Implement and analyze Data Structures and Algorithms
* Practice exception handling and Java Collections
* Write clean, readable, and maintainable code
* Understand Git and GitHub workflows
* Develop Java-based applications and projects

## Development Workflow

The general workflow followed for assignments and projects is:

```text
Understand the Problem
        ↓
Identify Requirements & Constraints
        ↓
Design the Solution
        ↓
Implement in Java
        ↓
Test Edge Cases
        ↓
Debug & Refactor
        ↓
Commit Changes
```

The focus is on understanding the underlying logic and developing efficient, maintainable solutions rather than simply obtaining the expected output.

## Git Workflow

### Clone the Repository

### View Branches


## Commit Convention

Commits follow a consistent format:

```text
feat: add new functionality
fix: resolve palindrome logic
docs: update README
refactor: improve array solution
test: add test cases
chore: update project configuration
```

| Prefix      | Description           |
| ----------- | --------------------- |
| `feat:`     | New functionality     |
| `fix:`      | Bug fixes             |
| `docs:`     | Documentation changes |
| `refactor:` | Code restructuring    |
| `test:`     | Tests and test cases  |
| `chore:`    | Maintenance tasks     |
